# Track2Data

Turn idtracker.ai output folders into analysis-ready behavioural datasets: 50 cited metrics,
documented units, and a record of which frames were measured or reconstructed.

The repository holds the version-pinned documentation — the user guide, the metrics
specification, the format analyses. This wiki holds what sits around it: how to get from an
export to a statistical result, what the terms mean, and what is currently in flux.
