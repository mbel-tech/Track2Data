# Track2Data

Turn idtracker.ai output folders into analysis-ready behavioural datasets: 45 cited metrics, documented units, and a record of which frames were measured or reconstructed.

- **Upgrading?** Check the [changelog](https://github.com/mbel-tech/Track2Data/blob/main/CHANGELOG.md) first; metric definitions are still being corrected (pre-1.0).
