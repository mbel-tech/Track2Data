# FAQ and Troubleshooting

Troubleshooting lives in the guide: [Troubleshooting section](https://github.com/mbel-tech/Track2Data/blob/main/docs/guide/USER_GUIDE.md#troubleshooting).

For bugs or questions not covered there, open an issue: <https://github.com/mbel-tech/Track2Data/issues>

Quick pointers:

- A `READER_OPTION_MISSING` error means the folder does not record a value (such as frame rate); pass it with `--option`.
