# 3-D movement: roadmap

**Status:** approved 2026-10-08. Sub-project C is in progress; E (mode switch) is implemented; A, B and D are not started.
**Relates to:** `docs/dev/DECISIONS.md` D-031, `docs/dev/ROADMAP.md` (Z-10),
`docs/tracker-formats/2026-10-07-tracker-import-design.md` (Tier 3)

"Integrate 3-D movement" is four independent projects. Each gets its own spec, plan and
build cycle.

| | Sub-project | Needs first |
|---|---|---|
| **C** | **Side-view depth**: a camera-view setting and a continuous vertical-position metric from ordinary 2-D side recordings | nothing unmerged, no 3-D data |
| **E** | **2D/3D project mode**: `ProjectManifest.mode`, Project-screen choice, lock, 3-D compute blocked. Done; see [the spec](2026-10-09-mode-switch-design.md) | nothing |
| F | **Panel split**: one video with the top and side views in two panels becomes two sessions (a panel rectangle per session, panel-relative coordinates). In design; see [the spec](2026-10-09-panel-split-design.md) | E |
| G | **ID correspondence**: view roles, pairing top and side sessions (regex or by hand), fish mapping between views, a Views step. Done; see [the spec](2026-10-09-id-correspondence-design.md) | E |
| A | Read 3-D tracker files (Anipose pose-3d CSV, DLC-3D). Metrics run on a chosen plane and z is stored (D-031 as written) | `feat/native-units` merged |
| B | Metrics that use z: 3-D speed and path length, vertical position, 3-D neighbour distance. **Amends D-031** | A for data, C for the vertical-axis setting |
| D | Fuse top and side recordings into one 3-D session | B's data model, frame sync, identity matching across views |

**Order: C, A, B, D.** A moves first if real 3-D files turn up. C goes first because no data
of any kind exists yet, it is testable on synthetic tracks, and it creates the project-level
camera-view setting that B reuses.

## Hand-offs between the sub-projects

- `KeypointSelection.plane` and `camera_view` have no defined precedence. A and B must define
  a vertical axis for 3-D data.
- The `has_pixel_frame` guard from native-units joins the IL-15 extent derivation when A lands.
- Per-session camera views arrive with D (`Engine.camera_view_for(session)` is the seam).
- Whether IL-3 and IL-14, which assume a top-down view, should be gated for side views is
  left open.
